description: Record an evidenced decision not to reply
---

Read CLAUDE.md, then run:

```bash
npm run reviews -- no-response --review=<id> --reason="<reason>" --actor="<operator>"
```

Keep the review in every record and report. A no-response decision does not remove or hide it on any platform. Require the operator’s reason; never apply this automatically to a low rating.

Writes require the operator’s supplied --actor. Keep evidence, exports and drafts private. Send nothing.
