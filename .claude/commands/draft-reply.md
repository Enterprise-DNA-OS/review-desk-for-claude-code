Read CLAUDE.md, then run:

```bash
npm run reviews -- draft-reply --review=<id> --file=<private-text-file> --evidence="<facts supporting wording>" --actor="<author>"
```

Read detail and history first. Use only verified facts. Write the proposed response in a private text file under drafts, then run the command. It creates an immutable database draft and a text copy in drafts. Do not expose account details, invent a remedy or imply a refund was approved. Never send or post.

Writes require the operator’s supplied --actor. Keep evidence, exports and drafts private. Send nothing.
