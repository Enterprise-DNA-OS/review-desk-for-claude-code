# Why there is no front end

The daily review desk needs a response queue, a location summary, evidence checks and service follow-up. Those are records and questions. A trusted operator can ask Claude Code, Codex, OpenCode or Cursor to run the matching command and explain the result. Read-only HTML gives the manager a report in the business’s own name.

This base is useful with exported review history and manually recorded responses. It has no phone app, drag-and-drop inbox, public review form, offline mobile workflow, live platform collector, authenticated client portal or automatic publishing. Grade.us also provides collection, connected responses and widgets. Those are real services beyond the records rebuilt here.

Choose this base when you want control over imported review evidence and response work, and can operate exports or commission the required connections. Enterprise DNA can build the shared screens and permitted platform connections around your version. The review platforms still own their networks and control account access. This project does not replace Google, Facebook or another review network.

A local HTML file is a snapshot and carries no access controls. It must be kept private. New views are reports over the database, never a public review ranking or a selectively positive testimonial feed.
